# Packet Capture and Analysis Project

## Overview

This project captures network traffic packets using `pyshark` and analyzes the captured data. It performs the following:

1. **Packet Capture**: Captures packets from a specified network interface and saves them to a `.pcap` file.
2. **Packet Analysis**: Analyzes the captured packets and generates statistics such as protocol distribution.
3. **Visualization**: Plots the protocol distribution in the form of a bar chart and saves it as an image.

## Requirements

- Python 3.x
- Wireshark (for TShark)
- Required Python libraries: `pyshark`, `matplotlib`
